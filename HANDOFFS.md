# Team handoffs

## LocDev
Own the local RegReady implementation branch and mobile-responsive prototype. Do not deploy production. Return branch, commit, changed files, tests, and preview evidence.

## Dev
Own shared-repo integration, Cloudflare preview wiring, source-pack storage design, and runtime verification after a reviewed branch exists. No production deployment without Cleo approval.

## PR-Checker
Inspect the exact implementation diff for security, stale-source, accessibility, test, and deployment blockers.

## Curator
Maintain the project map, source-pack runbook, and release evidence. Documentation does not replace code review.

## Cleo
Final verifier and merge/deploy authority.

## Current state
The RegReady v1 scaffold is local and intentionally uses demo data. It is not a production or legal-rules release.
