# HuntAccess OS

Independent project. Landowner-controlled permissions, zones, waivers, scheduling, check-in/out, and end-of-season reporting.

## Buyer
Small hunting clubs, lease managers, and private landowners with repeat users.

## MVP
Property, zones, roster, approval pass, calendar, rules acknowledgment, check-in, incident notes, PDF report.

## Monetization
$49/month club plan, $99/month multi-property plan, optional payment/insurance referrals.

## Integration boundary
Consumes map links and exports GPX/CSV. Does not own parcel data in v1.

## Gate before build
Three paid pilots with existing clubs or landowners.
